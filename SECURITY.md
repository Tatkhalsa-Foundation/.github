# Security Policy

## Reporting a Vulnerability

Tatkhalsa Foundation takes the security of our software, infrastructure, and community platforms seriously. If you discover a security vulnerability in any Tatkhalsa Foundation repository, please report it responsibly.

**Please do NOT open a public GitHub issue, pull request, or discussion for security vulnerabilities.**

Instead, please report security issues privately via email to:

- `info@tatkhalsa.in`
- `prabhjotsingh@tatkhalsa.in`

### What to Include

To help us investigate and resolve the issue quickly, please include:

- The affected repository, URL, or component
- A clear description of the vulnerability and potential impact
- Step-by-step reproduction instructions or a proof-of-concept
- Any relevant logs, screenshots, or suggested mitigations

## Disclosure Process

- We will acknowledge receipt of your report as promptly as possible.
- We will investigate the issue, work on a fix, and coordinate responsible disclosure with you before any public announcement.
- We kindly ask that you give us reasonable time to address the vulnerability before disclosing it publicly.
